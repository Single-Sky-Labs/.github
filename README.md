# Single Sky Labs · shared repository defaults

GitHub uses the files in this repo as defaults for every repo in the
`Single-Sky-Labs` org that has no copy of its own:

- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md): used for every PR
- [`CONTRIBUTING.md`](CONTRIBUTING.md): branch, review and secret rules

This repo is **public** because GitHub only applies org defaults from a public
`.github` repo. Never put code, internal URLs or secrets here.

Changes to these files change the rules for every repo. Open a PR and get the
other engineer's approval.
